8話 別人

2026-09-05 更新 | 2811文字

  • 前の話
  • 作品トップへ

　ニオラガンはラガンから歩いて一日の場所にある大きな集落だ。俺が用心棒を務めている県公認の娼館があるので、俺は週に六日、仕事でニオラガンに滞在している（※作中の暦では一週間は十日）。

　俺はサクの話の裏を取るために知人のニリチに会うつもりだった。ニリチは娼館の認可と監督を担当する中級の役人で、噂話に詳しい。

「サク。お前がいると面倒だから一人で行きたい」
「良いけど、私に憑かれていることは口外しないで」
「何で？」
「面倒を避けたいの。私の正体を知ったやつは片っ端に口封じするから」
「脅しか？」
「脅しじゃなくて予告。獲物以外の人間を傷つけるのは嫌いだけど、安全と効率のためならやらざるを得ないの。わかるよね？」

　サクに挑んでミンチになった這狼の群れを思い出すと、俺は「わかった」と返事をするしかなかった。

　ニオラガンは広いが、どうせニリチは仕事をサボっている。自宅を訪ねると、案の定ニリチがいた。外出の準備中なのか、背負子しょいこに荷物を詰めている。

「よお、ニリチ。話がしたい」
「レ、レゾ！？　お前、生きてたのか！？　この後ラガンに行こうとしてたんだよ。大変なことになってるって聞いたから、当面の食い物と傷薬でも持っていこうと思ってな」

　ニリチは四十代半ばだが、年齢の割にすっきりした見た目で、一見すると真面目で善良に見える。だが、実際は腐敗役人のお手本のような男だ。
　ニリチは俺とネデルに娼館の仕事を紹介してくれた男だ。俺は十四歳の頃から用心棒として、ネデルは十六歳の頃から男娼として娼館で働いて生活の糧を得ていた。ニリチの手回しのお陰で俺達は正当な労働の対価を受け取ることができ余裕のある暮らしを送れたが、問題なのはテナ人の成人年齢が十六歳であることだ。ネデルはギリセーフだが、当時十四歳の俺に用心棒をさせるのはかなりマズかったはずだ。
　俺はニリチを悪辣だと思ったことは一度もない。仕事をくれたことには感謝しているし、やつの役人としての手腕はある程度尊敬も信用もしている。だが、早い段階で「こいつは悪党だな」と確信したから、仕事仲間として最低限の関係しか築いてこなかったつもりだ。正直、ニリチがラガンまで遠出をするほど俺の心配をしてくれているのは意外だった。

「ラガンには行くな。死肉目当ての這狼だらけだよ」
「シラとネデルは無事か？」
「死んだ。骸禍天のせいでラガンは壊滅。生き残りは多分、俺だけだ」
「……そうか。将来有望なやつらだったのに、かわいそうにな」

　ニリチは右手の指を伸ばし、親指を上に向けて三度上げ下げする。テナ人が弔意を表す所作だ。

「レゾ、お前も気の毒だな」
「ああ、残念だ。でも心配は要らないよ」
「…お前、いつの間にそんなに打たれ強くなったんだ？　まあ、大丈夫ならそれでいいけどな。で、話って何だ？」
「役人の死体が見つかった事件について情報を集めてる。何か知らないか？」
「ああ、県都の役人が刺殺された事件だろ？　実は俺もその件について調べてるところだったんだ。レゾはトルグを知ってるか？」
「救貧舎の代表のトルグ？」
「うん。トルグは俺のダチなんだけど、あいつ、普段は宿屋を経営してるんだよ。ムボはトルグの宿に泊まってたらしいから、食事がてら話を聞きに行こう。あいつの宿はとにかく飯が旨いんだ」

　ニリチは俺が事件のことを調べている理由を聞かなかった。俺はこいつのそういうところを気に入っている。

　トルグは宿屋でまかない料理を食っている最中だった。結構なじいさんで、喋りはハキハキしているが一目で病人とわかるほど顔色が悪い。正直、老い先はかなり短そうだ。

「よお、ニリチ。またサボりか？」
「俺の部署は部下が育ってれば普段は暇なんだよ。金を払うから俺とコイツにも何か食わせてくれ」
「俺が食い終わってからな。あ、そっちの厳つい男はもしかして、用心棒のレゾか？」
「そうだけど、あれ？　俺達初対面だよな？」
「救貧舎の活動の一環で娼館を引退した娼婦や男娼を俺の宿で雇ってるんだ。あんたの元同僚から最強の男だと聞いてるよ」

　言われて気付いたが、厨房の何人かが俺に向かって親し気に手を振っている。娼館の元同僚たちだ。

「ニリチ、今日は飯を食いに来ただけか？」
「いや、違う。役人が刺し殺された事件について調べてるんだけど、何か知らないか？」
「ムボの件ね。噂以上のことで俺が知ってるのは、ムボは『ビシテマは権力者だから木端役人の告発なんて簡単に揉み消える。メリチシに協力を仰ぐつもりだ』って言ってたよ」
「メリチシか。噂には聞いてるよ」

　メリチシは成功している装飾品の工房経営者で、救貧舎の幹部を務めている女だ。子供のころ救貧舎の世話になっていた時期があるシラに何度かメリチシの話を聞いたことがある。

　ニリチはトルグの話に首をかしげた。

「ムボはどうしてメリチシならビシテマを止められると思ったんだ？　メリチシが優秀な女なのは知ってるが、さすがに首飾り屋の女主人には荷が勝ちすぎる相手だろ」
「俺も詳しくは聞いてない。何かあるとしたら、二人は同郷でそれなりに仲が良かったらしいんだ。多分ムボはそのことを知っていて、何か弱みでも握ってると期待したんじゃないか？」
「あるいはムボも大したアテは無くて、藁にもすがる思いでメリチシを頼る気だったのかもな。メリチシと話したいんだが、何とかならないか？」
「週末に救貧舎の会合がある。メリチシも来るから、会合の後に話せるよう段取りしてやるよ」

　その後、俺達は宿で飯を食って解散することになった。ニリチが言う通り、トルグの宿の飯は絶品だった。

「レゾ、今日はおごってやる」
「そいつはありがたい」
「なあ、レゾ。お前、何かあっただろ？」
「……大ありに決まってるだろ？　四日前に故郷が滅んで何もかも失ったばかりだ」
「いや、違うな。お前、ちょっと冷静すぎるぞ。まるで別人みたいだ」
【レゾ。ニリチには気を付けて】

　急にサクの声が響く。ニリチには聞こえていないようだ。

【その男はレゾが思ってるより勘が鋭い。余計な詮索はさせないで】
（助言をありがとう、クソ化物）

　俺の考えがサクに届いている気配はない。ニリチがサクに消されるのを避けるため、俺は一芝居打つことにした。

「ニリチ、この絵を見てくれ。ネデルが俺の結婚祝いに描いてくれた絵だ」

　俺はネデルの絵をニリチに見せた。

「わぉ！　相変わらず大した絵だ」
「ネデルが俺に向けたメッセージを感じないか？」
「あいつの人生観を考慮すると、『人生は闘いの連続だ。勝ち続けてシラに相応しい男になれ』だな」
「俺も同じような解釈だ。ダチの遺言。それが理由だ」
「……そうかよ。まあ、あまり無理はするなよ。ネデルも馬鹿じゃない。人が一日二日で変われるなんて思っちゃいないさ」

　別れ際、俺はニリチが目に涙を浮かべているのを見た。ニリチにとって俺達は存外、ただの仕事相手以上の存在だったのかもしれない。
