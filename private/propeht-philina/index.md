# outline
ケト王国の田舎シェイローネに生まれたフィリーナは、異能者の証である銀の虹彩を持って生まれ、周囲の期待を集める。しかしフィリーナはいつまでたっても異能に目覚めないばかりか、家業でもてんで役に立たず、徐々に周囲から軽んじられ始める。フィリーナは家族にも男友達のガゾにも「意気地なしは卒業しろ」と叱咤される日々を過ごすが、ついに異能が目覚めて……

目覚めた異能で成り上がり！　宝物、広い家、マッチョ外国人の夫！　夢魔、キレる王子、そして……ドラゴン！？  
元いじめられっ子の勇気が村の命運を左右する。「意気地なし・役立たずのフィリーナ」は大切な人たちを守れるのか、それとも――
