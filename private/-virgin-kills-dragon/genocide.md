# title
皆殺し
# number
130
# content
　賊徒はやはり素人集団らしく、四人は難なく寄合所の裏手に回った。寄合所はときたま酔漢が出入りしており、中からは酒宴の気配がある。
「全員小声でしゃべって良し。カウィン、中の人数はわかるか？」
「十人より多いのは間違いないが、詳しくは……」
　四人は既に、別の建物に監禁されているミテミの女たちを見張っていた賊を二人殺している。敵は残り、十九人。
「オレ達はもう敵を三人始末している。殺しが敵に露見すると警戒されて面倒だ。可能性は低いが、最悪逃亡される恐れも――」
「ルトン、ちょっと黙ってくれ。中の声が聞こえそうだ」
「ああ、すまん」
　カウィンはしばらく壁に耳を押し付けていたが、やがて攻撃的な笑みを浮かべ始めた。
「……へへへ。みんな、中にいるのは十三人だ。残る六人は外出中みたいだが、詳しくは中の連中を拷問して聞き出そう」
「すごい地獄耳だな、カウィン。どうして十三人だと？」
「声がでけぇヤツがギャーギャー騒いでるんだよ。『ミテミの女を早くレイプしたいから、六人が帰ってくる前に今ここにいる十三人でゲームして順番を決めようぜ』ってな」
「ねえ、もう皆殺しにしちゃいましょうよ」
　セマッカリが待ちきれない表情で|爆弩<ばくど>を構える。クーテも怒りのあまり額に青筋を浮かべている。
「よし。次に入口の扉が開いたら突入だ。全員覚悟を決めろ」
　待つことおよそ五小刻。一人の男が千鳥足で出てきた。ルトンが棍棒のフルスイングで男の顔面打ち砕いだ血しぶきが戦闘開始の合図となる。カウィンが室内に殴り込み、すぐさま異変に気付く。
「女だ、女がいるぞ！」
　半裸の若い女が、賊徒の中でも飛び切りの大男に抱き寄せられ、酌を強要されている。
「クズ共、皆殺しにしてやる！」
　セマッカリが躊躇なく爆弩を連射する。爆弩は|氷爆石<ひょうばくせき>という、強打すると指向性の強い冷たい爆風を発生させる魔石の力で金属の弾を飛ばす飛び道具だ。セマッカリは無茶苦茶に乱射しているように見えるが、爆弩のばね仕掛けの機構が氷爆石を叩く「カーン」という甲高い音が鳴り響く度、賊が一人倒れる。
「おい！　この女はミテミの――」
　数人の賊が半裸女を人質にすることを思いつくが、半裸女は既に大男を瞬殺したクーテの庇護下にある。爆弩の弾が切れたセマッカリが室内で槍を器用に振り回し、カウィンが素手で次々と賊の首をへし折っていく。寄合所の入り口は棍棒を構えたルトンが塞いでいて逃げ場はない。寄合所は狩場と化している。
「みんな、勝負ありだ！　もう良いぞ！」
「死ねぇっ、テナ人の恥さらしが！」
「セマッカリ、もうやめろ！　何人かは生かして情報を聞き出す！」
　ルトンに取り押さえられ、セマッカリがようやく停止する。息がある賊はあと四人。一人は重傷、残る三人はほぼ無傷だが完全に戦意喪失し、クーテに縄で縛りあげられている。カウィンたちは軽傷を負ったが、全員命に別状はない。
「賊徒のみなさんっ！　こんばんわ！」
　カウィンが狂気的な笑みを浮かべて声を張ると、四人が怯んで身を縮こまらせた。
「四人もいたら見張りづらいな。とりあえず数を減らすか」
　カウィンは重傷の賊の顔面を蹴り飛ばして首の骨をへし折ると、目をカッと見開いて怒鳴り散した。
「おい、クズども！　俺達の目的は拷問だ。目をえぐるぞ！　チンコを切り落とすぞ！　雄の労獣にレイプさせるぞ！　嫌なら俺達に奴隷のように従え！　わかったか！？」
　三人が必死の形相で頷く。
「ボスはどいつだ？」
　三人がほぼ同時に、カウィンがさきほど首の骨を折った男を指さす。
「おお、この弱っちそうなやつか！　お前ら、まだ仲間がいるよな？　どこだ？　いつ帰って来る？」
「く、詳しい居場所はわからないが、次に襲う集落を下見するために遠出してる。帰ってくるのは明日の夜だ」
「けっ、強欲なやつらだ。ミテミの獲物すら守り切れてないのに、まだ金と女がほしいかよ」
　カウィンが吐き捨て、目線でルトンにバトンを渡す。
「オレはこいつらの言うことに嘘はないと思う。こいつらを見張りながら六人が帰るのを待ち、不意打ちで仕留めよう」
「わかった。じゃあ、この三人はもう要らないよな？」
　カウィンがねっとりした視線を三人に送ると、三人が必死の命乞いを始めた。
「ま、待て、待ってください！　悪かった、本当に俺たちが悪かった！」
「聞いてくれ、俺達は最初からこうだったんじゃない！　州の仕事で食ってたんだが、ここ最近州も貧乏で仕事が無くなって、食うに困って盗賊の真似事を――」
「やかましい！」
　怒り狂ったセマッカリが槍を賊に向ける。だが、クーテが槍の前に立ちふさがった。
「どいてよ、クーテ！」
「セマッカリさん！　もうここまでにしましょう！　この人たちはもう戦えません！」
「はっ！　甘いわよ、クーテ！　こいつら、どう考えても食うため以上にミテミから奪ってる！　良い？　私はこいつらの言うことが一から百まで嘘とは思ってない。多分最初は、本当に食うためのモノしか奪っていなかったんじゃない？　でも、こいつらは完全にエスカレートして、枷を失っている。この先も被害者面で人を殺し、家畜と食料を奪い、女を犯すに決まってるわ」
「そうかもしれません。でも、今この人たちを殺すのは僕たちの役目じゃないはずです。守衆に引き渡す。それで十分じゃありませんか？」
「だーかーらー！　それが甘いって言ってるんだけど……！」
　二人はしばらくにらみ合っていたが、ついにセマッカリが折れ、槍を降ろした。
「クズ共。クーテの博愛の精神に感謝することね。クーテの良心を裏切ったら、私がお前らを死ぬより辛い目に遭わせてから殺すわよ」
　三人は小便を漏らして震えながら、壊れた人形のように首肯した。
