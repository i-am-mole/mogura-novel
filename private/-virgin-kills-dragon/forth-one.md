# title
最後の勇者
# number
50
# content
　勇者の選抜を開始して早々、サンデンでは三人の勇者が見出された。バンは大手柄に笑顔が止まらない様子で、毎日のように酒場でどんちゃん騒ぎを繰り広げている。

「俺は地元がサンデンに近いからって軽い気持ちでここの試験監督に応募したんだが、まさか三人も強者が見つかるとはよぉ、大手柄だ！　地元の壊れた水道管を修繕できるぜ」
「なあ、バン。州は勇者を何人集めるつもりなんだ？」
「四人だ。今朝報告があったんだが、他所の選抜会場でついに集落で四人目も見つかっている。もう数日でサンデンに到着するってよ」

　カウィンたちは旅の支度を少しずつ整えながら、人間関係を深めることにつとめた。
「改めて自己紹介をしましょうか。私はセマッカリ。フルネームはセマッカリ＝ウルル＝ヨウデンね。今年で二十二歳。同朋をグォンサムの脅威から救うために郷土防衛隊を抜けて勇者に立候補したの」
「え、セマッカリって郷土防衛隊にいたのか？　正規兵か？」
「うん。私の祝福は『不射の射』って言って、弓を撃つジェスチャーをするだけで分厚い金属板も貫く空気の弾丸を放つことができる。軍では特殊部隊に所属して、普通の武器が通用しない妖を殺しまくってたわ。一発撃つと反動で半日は動けなくなっちゃうから、祝福を披露するのはまたの機会ね」
「めちゃくちゃエリートじゃねぇか。金も名誉も間に合ってるだろうに、どうしてわざわざ勇者なんかに？」
「えっ？　だから、同朋をグォンサムの脅威から救うためだって」
　腑に落ちない表情を浮かべるカウィンに、セマッカリが歯茎をむき出しにして敵意を示す。
「私はね、自分で言うのもなんだけどエリートなの。父は県の建築部門の責任者で、篤志家の母は私財をはたいてサンデンに公衆浴場を三つも建てた。祖父は郷土防衛隊で方面司令官にまで昇りつめて、非番中に妖に襲われている民間人を助けようとして死んだわ」
「はぁ。親がご立派なのはわかったが、それがお前に何の関係が？」
「つまりね、私くらいのエリートになると自分の幸せのために生きたりなんかしないの。祖父たちのように、如何に同朋の困難を排除し、利益を最大化するかが私の人生のテーマよ。山でおちんちん遊びして育った露出狂には理解しがたい生き様かしら？」
「けっ。エリート様の覚悟がホンモノか、俺が見定めてやるよ」
 　カウィンはマズいものを吐き捨てる仕草で応じた。
「そういうカウィンはどうして勇者に？　女にモテるためって噂で聞いたんだけど、まさかね？」
「いや、そのまさかだよ」
「はぁ？　くたばれ、脳みそチンコ野郎！」
「俺は真剣だ、尻薄チビ女！」
「まぁまぁ落ち着けよ、二人とも」
　ルトンが犬の喧嘩をなだめるように仲裁する。ルトンはカウィンたちより少し年上で、軽薄そうな外見に反して年齢相応の落ち着きがある。
「そういうルトンはどうして勇者になったんだ？　お前も女目当てか？」
「笑わせるな。オレは顔立ちがチャラ男っぽいし、女好きなのは認めるけど、別に女には困ってないよ」
「うっ」
　嫉妬に心臓を貫かれ、カウィンが胸を抑えてもだえる。
「オレは普段は実家の畑を手伝いながら県の委託を受けてドクェ県各地の植生を調査している。職業柄、山でのサバイバルには慣れてるからそこは期待してくれ。勇者になった目的は金だ。わけあって、まとまった金が必要でね」
「カウィンは女、ルトンは金。私以外の勇者は全員私利私欲の強欲野郎ってわけ？」
　セマッカリがみるみる不機嫌になるが、ルトンは意に介さない。
「セマッカリの要求は厳しすぎて非現実的だ。何の利も無いのにドラゴンに挑むやつがそう何人もいてたまるかよ」
「まあ、それはそうかもしれないけどね」
「それに、私利私欲と言ってもオレの金の使い道は一応――」
　その時、遠くから「おーい！　勇者のみなさーん！」と声がした。馬上から誰かがこちらに手を振っている。
「お待たせして申し訳ありません！　四人目の勇者クーテ、今到着しました！」
　クーテが明るく品の良い笑みを浮かべる。低く太い声、まくったシャツから除く前腕は筋肉で太いが、顔立ちと髪質は女のようだ。目立つ容姿だが、やはりカウィンの目を惹いたのは稀人の証である銀眼だった。
「自己紹介の途中だったでしょうか？」
「ああ。このセマッカリ様に名乗りをあげて、勇者に志望した動機と祝福をご報告差し上げろ。それが勇者パーティの掟だぜ」
「黙れ、カウィン。クーテ、この馬鹿の言うことは気にしなくて良いけど、自己紹介をお願いできる？」
「あはは……では、名乗らせていただきます。僕はクーテ。ニオイデオから来ました。平地育ちなのでサバイバルは不慣れですが、体力と器用さには自信があります。見ての通り稀人なので、祝福でみなさんの旅のお役に立たせていただきます」
　クーテがおもむろに街路樹に触れると、枝の先端からじょうろのように水が降り注いだ。
「『清流』の祝福です。ご覧の通り、植物や地面から綺麗な水を抽出することができます。戦いの役には立ちませんが、僕がいれば飲み水とお風呂に困ることはありませんよ」
「すごっ！　良いわね、これ」
「ああ、重たい水を持ち運ばずに済むのは大きいぞ。それにしても、稀人が二人もいるなんてすごいな」
「風呂に入り放題なのも最高だ！　いいぞ、クーテ！」
「はい、ありがとうございます！」
　三人の絶賛に、クーテが素直な喜びの表情を浮かべる。
「僕は普段は実家の|紅果<こうか>農場を手伝っています。勇者に立候補した理由ですが、セマッカリさんに命を救われた恩を帰すためです。風の噂でセマッカリさんが勇者になったと耳にしたので」
「えっ？　私？」
「セマッカリさん。五年前の雨季に|翼虎<よっこ>に襲われている家族旅行の一団を助けたのを覚えていませんか？」
　クーテの声音には熱がこもっている。
「ん……？　あっ！　思い出した！　えっ！？　クーテがあの場にいたの？」
「はい。いつまでも塞ぎこんで、セマッカリさんにずっと『よしよし、もう怖くないからね～』されていた子供が僕です」
「あーっ！？　あの子ね、覚えてる、覚えてる！　ごめんなさい、あまりに可愛い子だったから、女の子だと記憶してたわ！」
「えっ――」
「クーテったら、すっかり声変わりしてマッチョになっちゃったから、あの子だとは気付けなかったわ。それにしてもあんた、本当に可愛い顔してるわね。妹にそっくりよ」
「いっ、妹……旅では男らしいところも見せられるよう頑張ります」
　クーテがあからさまに落ち込む。意中の相手に異性とすら見なされていなかったことにショックを受ける若者の顔だと、恋愛未経験のカウィンですら一目でわかった。
「おい、ルトン。どう見てもクーテはセマッカリに惚れてるよな？」
　カウィンの小声に、ルトンが苦笑いで肯定の意を表す。
「イカれたエリート主義者、金目当ての寝取り顔男、恋愛脳の雌顔男子……このパーティ、本当に大丈夫かよ？」
「悪いがカウィン、異常性欲で露出狂のオナニー中毒者に心配されるほど駄目なヤツは、今のところこのパーティにはいないぜ」
　カウィンとルトンが取っ組み合いのけんかを始める。セマッカリとクーテは旅の行く末を心配し、深いため息をつくのであった。
