# outline
テナチ王国ヤマ州議会は、宝を求めて北部の都市トーリを幾度となく襲撃した火竜グォンサムを討つために、少数精鋭の勇者をグォンサムの根城ヒースに派遣する特殊作戦を立案した。ドクェ県の山村ボヤに住む青年カウィンはドラゴン討伐報酬に目が眩んだ姉にまんまと乗せられ、ドラゴン討伐の名誉を餌に女にモテることを目指し、勇者に名乗りを上げる。集いし勇者は異常性欲者カウィンの他、イカれたエリート主義者のセマッカリ、寝取り顔のルトン、博愛主義で恋愛脳のクーテ。こんなやつらに、本当にドラゴンを討てるのか？
