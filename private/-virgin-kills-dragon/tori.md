# title
トーリ
# number
180
# content
　卑竜との遭遇から七日後。一行はついにアンガンを抜け、その先に広がるダッターラという高原も難なく踏破し、トーリの門を叩いた。
「すげぇな、これがトーリか」
　カウィンがただでさえ大きな目をかっと見開く。トーリは高地を切り開いて作られた大きな集落で、市街地全体が石壁と妖除けで囲まれている、石壁の上では、機械弓らしき武器を搭載した車輪つきの乗り物を労獣が曳いている。

　一行がしばらく待つと、門番が上級武官らしき壮年の偉丈夫を連れてきた。
「トーリの将セランシを補佐する主席軍師のムボだ。用件を聞きに来た」
「サンデンでドラゴン殺しの勇者に選ばれたルトンだ。勇者カウィン、セマッカリ、クーテもいる。待たせてすまなかった」
「旅にトラブルはつきものだ。将軍は今出張中だ。帰るまでの間、長旅の疲れを癒してほしい。そちらの一番大きい方は、どうやら火傷を負っているようだが、治療は間に合っているか？」
「七日前に卑竜を二頭始末した時の怪我だけど、もう治ってるよ」
　カウィンはムボが高位の武官だと察している。公権力に弱いカウィンだが、勇者になって気が大きくなっているのであまりへコヘコしなかった。
「二頭の卑竜をたった四人で？　犠牲も無く？」
「ああ。楽な戦いではなかったけど、卑竜も|偽竜<ドラゴン>の一種だし、良い経験になったよ」
「何と頼もしい……テナ人の未来は君達にかかっている。初対面の若者に身勝手な物言いだが、どうか使命を果たしてくれ」

　ムボは一行のためにトーリで一番大きな宿を手配した。
「それにしても大きな集落だな」
　宿の窓からトーリの街並みを見渡し、カウィンが呟く。
「ここ、グォンサム対策のために建てられた集落なのよね？　こういう場所、ヤマ州の南にある人類と妖の領域の境界にも多いんだけど、成人のほとんどが軍関係者のはずよ。税が軽かったり、怪我の治療を州が全額補助してくれたりする特権の代わりに、軍事的貢献を求められるの。他所への引っ越しにかかる移転料もバカ高くて、とてもじゃないけど引っ越せないわ」
「一生ここに住んでグォンサムと戦うのか。何ていうか、想像がつかない世界だな。オレには間違いなく向かないよ」
「すこし集落を散策しませんか？」

　集落へ繰り出した一行に、住民たちに次々に絡む。四人が勇者であることが早くも集落に広まっているのだ。
「見ろよ、あれが噂の勇者らしいぜ」
「稀人が二人もいるぞ。きっと将軍みたいにすげぇ超能力が使えるんだろうな」
「他の二人も見てみろよ。あんな厳つい男、正規兵にも滅多にいないぞ」
　勇者だからが、あるいは単に余所者が珍しいのか、まるで見世物である。
「お父さん、見て。あの一番大きい男の人、左目がずっと違う方向を見てるよ。何で？」
　カウィンの地獄耳が七歳くらいの男の子の呟きを捉える。
「おい、坊主～！　お兄ちゃんが答えを教えてあげるからな。一つ、俺の左目は外斜視って言うんだ。二つ、これは生まれつきだから、『何で？』とか理由は無いぞ」
「変な顔！」
「やんのかクソガキ！」
　父親が半泣きで謝罪するのを脇に置いてカウィンが男の子に絡む。カウィンはなぜか子供や動物にはすぐになつかれる上、いじられキャラになることが多い。

　四人はすぐに気付いたが、やはりトーリは明らかに普通の集落ではない。
　テナ人は基本的に木で建物を建てるが、トーリの建物に木造のものはほとんどなく、石造りが大半だ。
　火消役人の詰め所があちこちにあり、四人が見た範囲だけでも二つの詰め所で役人が住民の子供に消化訓練を施していた。消化は水をかけて行うのではなく、スリングで固形の消火剤を投擲して行うのがトーリ流らしいが、見聞が広いセマッカリとルトンにとっても初めてみる光景だった。
　住民は一様に大きな琥珀色の頭巾、通称「火鼠の衣」を被っている。耐火・耐熱性が高い特殊な獣毛で編まれたものだ。
　トーリは火竜グォンサムの脅威に対抗するために建てられた軍事拠点であり、あらゆる設備、物品がグォンサムとの戦いを最大の目的として存在するのだ。

　トーリ初日の夜。一行は宿に併設されている大きな食堂で食事をとっていたが、一行との会話目当ての住民が無限に湧いてくるので、結局カウィンの部屋で食事を夕飯を済ませた。
「すごい集落だな。とてもじゃないが、俺には一年と住めそうにないや」
　山育ちのカウィンにとって、火災対策で道から木も花も雑草も抜きはらわれたトーリの光景は、誇張抜きに死の荒野だった。
「集落っていうより民間人の居住区がある軍事拠点って感じね。男も女も鍛えてる体格の大人が明らかに多かったし、州軍時代の同僚みたいなやつが多くて笑いそうになったわ」
「ここの住民には悪いが、正直オレはトーリの雰囲気は苦手だな。何ていうか、落ち着かないんだよ。ミテミの方がここよりよっぽど――」
「勇者のみなさ～ん」
　給仕のソハンという若い女が部屋に入って来て、ルトンが口を閉じる。トーリをどう思っていようと、ここの住民にとっては一生を暮らす地なのだ。
「食堂をそろそろ閉めたいんだけど、最後に何か頼む？」
「おお、もうそんな時間か。最後に果実酒を一瓶、良いか？　お疲れさん、ソハン」
　ソハンは小走りで食堂に戻り、すぐに果実酒の瓶を持ってきた。
「ありがとよ、ソハン。お疲れさん。あんたも一杯どうだ」
「ありがとう、いただくわ。ねえ、トーリの街並みはどうだった？　変わった集落でしょ？」
「本当に、目に映る何もかもが新鮮でした。見聞が広まる思いです」
「あたし、ここはちょっと苦手。あはは」
　ソハンが果実酒を一気飲みする。
「四人はアンガンの方から来たのよね？」
「はい。ダッターラ高原を抜けてここにたどり着きました」
「ダッターラ高原って何もなかったでしょ？　実はあそこ、道路から少し外れた場所に数年前までダッターラっていう集落があったの。グォンサムの活動が活発になって、この辺のありとあらゆる軍事物資がトーリに集まるようになって、妖除けの香木の値段が高騰して維持できなくなっちゃったけどね」
　テナチ王国の多くの集落では妖除けが生活の生命線だ。妖除けは香木型、宝石型など種類は様々だが、要するに妖を退ける結界を張るための物資である。妖除けが無いと、集落は妖の脅威に直に晒されることになる。
「もしかして、ソハンさんはダッターラからトーリに移住を？」
「子供の頃にね。トーリで特権と引き換えにグォンサムと一生戦うか、自力で他所に移住するかを選べってなって、親がトーリを選んだわ」
「トーリはぶっちゃけどうですか？」
「うーん……変わった集落よ、ホント。トーリ生まれの人はチャラついたガキでも『グォンサムとの戦いに一生を捧げるんだ』って腹を括ってて、あのテンションについていけない人にはキツイと思う。住民もセランシ将軍も良い人ばっかりだし、ご飯は美味しいし、なんだかんだ言って特権はスゴイから、暮らしは悪くないんだけどね。あたしは性格がちゃらんぽらんだから、ちょっとこの集落は真面目過ぎるかなって」
　その日は結局、ソハンを交えて夜遅くまで飲んで駄弁ってお開きとなった。カウィンは久しぶりの柔らかな布団で、ソハンにグォンサムを討伐した礼に杭打ちピストン騎乗位をしてもらう妄想で五回射精すると、トーリの人々の暮らしに想いを馳せながら深い眠りについた。
