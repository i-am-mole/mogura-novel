# content
　俺はニオラガンに出張した時に泊まるための小さな小屋を持っている。公衆浴場で風呂を済ませて小屋に帰ると、サクが当たり前のような顔で待ち構えていた。

「お帰り、レゾ」
「どうしてお前がここに？」
「前にも言ったじゃん。私はレゾのことを夢で色々と聞き出せるんだって」
「そうか。あばよ」

　小屋を後にする。サクと二人きりになるのが恐ろしかった。

（サクにとって正体が露見するのは面倒なことらしい。夜のニオラガンは治安が悪いが、それを踏まえても野宿した方が安全か？）
「野宿作戦かな、レゾ？」

　サクがいつの間にか背後にいる。相変わらず気配も足音も無い。

「人目があれば大丈夫って考えた獲物は何人もいたけど意味無いよ。私の術を喰らうと、人前でもお構いなしにセックスするくらいおかしくなるから」
「その時はお前も正体がバレてお終いだ」
「確かに私も面倒なことになるけど、終わりはしないかな。目撃者を皆殺しにして、別人に化けてここを去るだけだから」
「そうか。あばよ」

　策はまだある。俺は勤務先の娼館に向かった。

「レゾ、あんた今日は休みだろ？　忘れ物でもしたかい？」
「いや、今日は客として来た」
「えっ！？」

　受付が目を丸くする。

「骸禍天のせいでラガンが崩壊したことは知ってるか？　あれのせいで俺の人生滅茶苦茶さ。何か気晴らしでもしないと、崖から飛び降りそうな気分だ」
「……そうかい。本当は用心棒に娼館を利用させるのは良くないんだけど、今回は特別だ」
「ありがとう」

　俺は案内された娼婦を抱きまくった。これがサクとのセックスを避ける第二の策。事前に精力を使い果たしてしまうことだ。
　俺を接客したのは娼館で一番体力がある同僚だったが、途中で体力の限界を訴えたので別の娼婦と交代し、二人目が疲労で寝落ちすると三人目を抱き、三人目が失神寸前で目を白黒させるころ、ようやく精も根も使い果たした。

（シラとの約束を守って大真面目に童貞を貫いてきたのに、シラが死んだ四日後にはシラに化けた妖に殺されないために娼館の同僚で童貞を捨てるなんてな……）

　あまりの情けなさにうっすらと涙を流す俺を見て、三人目の娼婦ソハンは何か勘違いしたらしく、俺の頭を優しく胸元に抱き寄せた。

「レゾ。大丈夫？」
「うん」
「……ねえ、レゾ。娼婦を抱いて辛い気持ちを誤魔化すのは良い手じゃないけど、本当に潰れるよりずっとマシだからね。アンタになら私、いくら抱かれても良いから。娼婦としてじゃなくて、ただの女としてね」

　相手がソハンでなければ恋愛感情を向けられていると思ったかもしれない。

　俺は五年前、娼館解体同盟に拉致されかけていたソハンを助けるために暴漢を三人殺している。
　娼館解体同盟は性産業の存在を否定し、県に全ての娼館の認可の取り消しを訴える民間団体だ。チヤレ県のあちこちに小さな寄合所を持っている。本来の娼館解体同盟は穏健な民間団体だが、ニオラガンの娼館解体同盟は例外だ。ニオラガンの娼館解体同盟は県公認の娼館から客と従業員を奪いたい非公認の娼館経営者に上層部を乗っ取られており、現場で活動しているのは下手なギャングよりよっぽど凶悪なゴロツキばかりだ。
　ソハンは当時、県公認の娼館の業務に最新の性病予防剤を導入するよう県に訴える草の根運動のリーダーをしていた。娼館解体同盟にしてみれば、県公認の娼館の職場環境を改善しようとするヤツは面白くない存在なわけで、不快なヤツは殺せと短絡的に命を狙ったわけだ。
　俺に命を救われて以来、ソハンは俺に対して罪悪感と崇拝に近い念を抱いている。俺の思い込みかもしれないし、そうであってほしいが、若干俺に依存気味だと感じることもあった。ソハンの申し出が嬉しくないと言えば嘘になるが、「じゃあこれからもヤらせてくれ」とは口が裂けても言えない。

「いや、気持ちだけ受け取っておくよ。こういう息抜きは今日これっきりにするって決めてるんだ」
「あら、やせ我慢？」
「おいおい、ソハン！　人生、やせ我慢をしなければならない時なんていくらでもあるだろ？　俺を同僚の女が股を開いてくれないと自分を泣き止ませることもできない男に仕立て上げる気か？」
「何それ、あはは！」

　俺にもう少し人生経験があればソハンにもっと良いことを言ってやれたのかもしれない。俺には精算するべき人間関係なんて無いと思っていたが、一ヵ月後に自分が死んでいる可能性が高いとなると、意外と気がかりが多いと気付いた。

　娼館を出ると、もう夜中になっていた。娼館を出てすぐのところにある小屋へと続く路地の入口で、いきなりサクと鉢合わせになった。

「童貞卒業お疲れ様、レゾ。次は私が相手してあげるね」
「うおっ！？」

　渾身のハイキックをお見舞いするが、サクはビクともしない。避ける間もなくふっと息を吹きかけられると、シナシナに縮こまっていたイチモツに一気に血が流れ込み、痛みを伴いながら勃起する。濁流のような性欲が思考を押し流していく。俺は頭の中で「止まれ！」と叫んでいたが、俺の両手は既にサクをその場に押し倒し、服を引き千切るように剥ぎ取っている。歯止めが効かないまま、サクの膣に強引にイチモツをねじ込んでいた。

「あっ！？」

　挿入したイチモツで感じるのは性的快楽ですらない、俺にはそれを表す語彙の持ち合わせが無い感覚だった。俺とサクがいるこの薄汚い路地裏を残して全てが消え去り、過去と未来が無価値になり、今すらも空虚になっていく。無意味になっていく世界の中で、サクと交わることだけが確かなこと、俺が現実に生きていることの唯一の証明だとしか思えなくなっていく。

「あっははは！　レゾ、上手、上手じゃん！」

　俺に暴力的に抱かれながら、サクは余裕綽々の笑みを浮かべている。シラのはにかみ笑いとは違う、歯をむき出しにした、妖の本性むき出しの笑みだ。サクの舌が子供の背丈ほどに伸び、俺の全身を舐め回している。その舌をしゃぶると唾液が果実のように甘酸っぱく、体内に甘やかな香りが広がり、イチモツが弾けそうなほど怒張する。サクの眼はシラと同じ濃い灰色だったが、それが今や金色に輝き、瞳孔は蛇のような縦長になっている。

（俺、喰われてるんだ……喰ってくれ……俺をこのまま殺してくれ……）

　俺の思考は停止し、捕食される喜びに浸りながら腰を振ることしかできなかった。
